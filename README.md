# RTA Command Center — Real-Time Adherence Dashboard

**Production-grade operations monitoring system** built for contact center and BPO environments.

## What It Solves
Manual RTA tracking creates a 15–30 minute lag between adherence breaches and corrective action.
This system collapses that to real-time, with automated alerts before SLA violations compound.

## Key Results
- Deployed at TikTok LIVE operations: team TPD increased from **14 → 40** while maintaining **100% QA / 0 DSAT**
- Replaces 8+ hours/week of manual KPI aggregation
- Auto-alert thresholds configurable per queue type and SLA tier

## Tech Stack
`Python` · `Streamlit` · `Pandas` · `SQL` · `FastAPI` · `Docker`

## Features
- Live adherence variance tracking per agent/queue
- Dynamic alert thresholds (configurable SLA tiers)
- CRM data simulation layer for demo/staging environments
- Exportable compliance reports

## Status
Production-ready · Containerized · Multi-tenant capable
